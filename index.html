👨‍👩‍👧 부모님 설정

🗣️ 목소리
더 자연스러운 목소리 설치하는 법

iPad / iPhone: 설정 → 손쉬운 사용 → 읽기 및 말하기 → 음성 → 한국어 → 유나 (프리미엄) 또는 유나 (향상됨) 내려받기 → 이 앱을 다시 열기

Mac: 시스템 설정 → 손쉬운 사용 → 읽기 및 말하기 → 시스템 음성 옆 ⓘ → 한국어 → 유나 (프리미엄) 내려받기 → Safari/Chrome 다시 열기

갤럭시: 설정 → 일반 → 텍스트 음성 변환(TTS) → 기본 엔진 Google 음성 인식 및 합성 (또는 삼성 TTS) → ⚙️ → 음성 데이터 설치 → 한국어 → 여성 음성 선택, 빠르기 보통

✏️ 획순 지키기
