# 한글 놀이터

6살 아이를 위한 한글 놀이 게임입니다. 하늘에서 내려오는 글자를 잡고, 그림을 보고 낱말을 고르고, 첫 글자를 찾고, 자음과 모음을 합쳐 봅니다. 별과 스티커를 모으며 놀 수 있습니다.

주소: https://podolsch-lang.github.io/hangul-game/

한 번 연 뒤 홈 화면에 추가하면, 앱처럼 전체 화면으로 열리고 인터넷이 없어도 이어서 놀 수 있습니다.

**따라 쓰기**에서는 자음, 모음, 받침 없는 글자, 짧은 낱말을 바른 획순으로 따라 씁니다. 손가락, 마우스, 애플 펜슬로 쓸 수 있습니다. 부모님 설정에서 **획순 지키기**를 켜 두면(기본값) 지금 차례의 획만 맞아요. 끄면 순서가 바뀌어도 그 획의 모양만 맞으면 됩니다. **자유롭게 써보기**에서는 글자를 고르고 크레용 색으로 마음대로 따라 그립니다.

## iPad Safari에서 홈 화면에 추가

1. **Safari**로 위 주소를 엽니다. (Chrome이 아니라 Safari여야 합니다.)
2. 화면 아래의 **공유** 버튼(네모 안에 위로 향한 화살표)을 누릅니다.
3. 목록을 내려 **홈 화면에 추가**를 누릅니다.
4. 이름이 **한글 놀이터**인지 확인한 다음 **추가**를 누릅니다.
5. 홈 화면의 아이콘을 누르면 됩니다.

## 갤럭시 Chrome에서 홈 화면에 추가

1. **Chrome**으로 위 주소를 엽니다.
2. 오른쪽 위의 **⋮** 메뉴를 누릅니다.
3. **홈 화면에 추가** 또는 **앱 설치**를 누릅니다.
4. **추가** 또는 **설치**를 누릅니다.
5. 홈 화면의 **한글 놀이터** 아이콘으로 엽니다.

## 구성

- `index.html` — 게임
- `manifest.json`, `sw.js` — 홈 화면 앱과 오프라인 저장
- `icons/` — 홈 화면 아이콘
- `audio/` — 미리 녹음한 목소리. MeloTTS(MIT)로 만들었습니다. 자세한 내용은 `audio/LICENSE.txt`를 보세요.
